# PHU-CAP-GS
TRA CỨU PHỤ CẤP
WEBSITE TRA CỨU PHỤ CẤP LAV-LA

Đã tạo dữ liệu từ file Excel của bạn.
Số nhân viên đọc được: 292

Các trường:
- STT
- Mã nhân viên
- Họ Tên
- KH_XAP CA
- Có phụ câp
- PC đặc thù (công)
- PC bốc bình ViVa

Tổng trên giao diện = Có phụ câp + PC đặc thù (công) + PC bốc bình ViVa.

CÁCH CHẠY THỬ:
Mở index.html bằng Chrome.

ĐƯA LÊN GITHUB PAGES:
1. Tạo tài khoản GitHub.
2. Tạo repository, ví dụ: tracuu-phucap.
3. Upload index.html, style.css, app.js, data.js.
4. Vào Settings > Pages.
5. Chọn Deploy from a branch > main > / (root) > Save.
6. GitHub sẽ tạo link website.

LƯU Ý BẢO MẬT:
Phiên bản này là website tĩnh và data.js chứa dữ liệu nhân viên.
Người biết kỹ thuật có thể tải data.js và xem toàn bộ dữ liệu.
Nếu phụ cấp là dữ liệu cần bảo mật, không nên triển khai phiên bản tĩnh này công khai.
